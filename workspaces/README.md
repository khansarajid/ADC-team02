# Member workspaces

Each member has a personal folder here — use it for your experiments,
notes, drafts, and work-in-progress before it goes into the main
project folders (src/, docs/, results/).

Rules:
- Only edit files inside YOUR OWN folder (avoids conflicts).
- Finished/agreed work gets moved to the proper shared folder.
- Always run `git pull` before you start working, and
  `git add .` → `git commit -m "message"` → `git push` when done.
